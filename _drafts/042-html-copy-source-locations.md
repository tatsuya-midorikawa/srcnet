# [P2] HTML で選んだノードの ID とソース位置をコピーできるようにする

- 種別: 使いやすさ / 成果物から次の調査への導線
- 起票日: 2026-09-27
- 依存: なし。031 の利用ガイドと操作例を連携させる。

## 確認した事実

- [HTML テンプレート](../src/Srcnet.Cli/assets/graph.html) の `select` は、パス・行範囲・ID をテキストとして表示し、隣接ノードへのボタンを生成する。
- 専用のコピー操作やソース位置へのリンクはない。既存の検索・選択・ズーム・フィルターは実装済みである。
- macOS の統合ブラウザーで、生成した 13 ノード・12 エッジの HTML を表示した。選択パネルのリンク数は 0、ボタンは隣接ノードの選択だけだった。
- 1280 x 800 と 390 x 844 で表示を確認し、横方向のはみ出しは検出しなかった。本件はレイアウト全体の置き換えではない。

## 利用者の困りごと

HTML で関係を見つけても、長い ID やパスを手動選択して CLI・エディターへ移す必要がある。共有された HTML では、元ソースと索引が手元にあるとは限らない。

## 改善内容

- 選択ノードに「ID のコピー」と「相対パス・行範囲のコピー」を追加する。
- まずコピーによる受け渡しに限定し、機械固有の絶対パスやエディター用 URL を HTML へ自動埋め込みしない。
- Clipboard API が使えないローカル HTML では、対象文字列を選択できる代替を提供し、成功・失敗を伝える。
- キーボード操作と読み上げ用の名称を備え、未選択やソース位置のないノードでは操作可能な内容を明確にする。
- 利用ガイドで、コピーした ID を `show` / `neighbors`、ソース位置を通常のファイル参照へ使う手順を示す。

## 対象外

ブラウザーからのコマンド実行、ソースの自動取得、外部サービスへの送信、HTML へのソース全文埋め込み。

## 受け入れ条件

- [ ] ID とパス・行範囲を個別にコピーでき、ノードの切替後に古い値をコピーしない。
- [ ] CJK・空白・引用符・制御文字を含む入力を安全に扱い、HTML やコマンドとして評価しない。
- [ ] ローカルファイルでの Clipboard API 拒否と代替操作を検証する。
- [ ] キーボードのみで操作でき、成功・失敗・位置なしを判別できる。
- [ ] macOS / Windows の対象ブラウザーで確認し、オフライン・単一ファイル・既存の表示上限を維持する。
