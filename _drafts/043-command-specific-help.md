# [P2] サブコマンドのヘルプを用途に合わせて表示する

- 状態: 未着手
- 種別: 使いやすさ / CLI の発見性
- 起票日: 2026-09-27
- 依存: なし。030 の入門手順へ誘導できるようにする。

## 確認した事実

- 現行 CLI で `srcnet --help` と `srcnet search --help` を実行し、同じ 54 行のヘルプが返ることを確認した。
- [Program.fs](../src/Srcnet.Cli/Program.fs) は `Args.Help` を受け取ると共通の `Args.usage` を出力する。
- [Args.fs](../src/Srcnet.Cli/Args.fs) と [クエリと CLI](../docs/query-and-cli.md) はコマンド別のオプション制約を持ち、例えば `--edge` / `--direction` は search では使えない。
- サブコマンドからヘルプを呼ぶ機能自体は実装済みである。本件はヘルプの新設ではなく、表示内容の改善である。

## 利用者の困りごと

使いたいコマンドの必須引数・有効なオプション・次の一手を知るために、他のコマンドの説明まで読み分ける必要がある。

## 改善内容

- 全体ヘルプはコマンド一覧と概要、サブコマンドのヘルプは該当する構文・オプション・既定値・短い実行例に分ける。
- `--root` と `--out`、検索文字列と NodeId、空結果と曖昧候補の違いを、関連するコマンドに限って補足する。
- ヘルプ表示に必須引数や索引を要求しない既存動作を維持する。
- 入力誤りから該当コマンドのヘルプへ誘導し、未実装オプションを利用例に混ぜない。
- 既存の引数解析を再利用し、ヘルプのためだけに新しい CLI パッケージを導入しない。

## 対象外

対話型ウィザード、コマンド体系全体の変更、シェル補完の同時実装。

## 受け入れ条件

- [ ] 各サブコマンドの `--help` / `-h` が必須引数なしで成功する。
- [ ] search のヘルプに search で使えないオプションを載せず、既定値と範囲がパーサーに一致する。
- [ ] `export html --help` など複数語のコマンドでも適切な説明を返す。
- [ ] `--` の後に置いた `--help` は検索文字列として扱う既存契約を維持する。
- [ ] [CliTests.fs](../tests/Srcnet.Tests/CliTests.fs) 等で内容を検証し、両 OS の端末で CJK の表示を確認する。
