## 確認した事実

- [ストレージ](../docs/storage.md) にバイナリ形式と世代公開の仕様、[クエリと CLI](../docs/query-and-cli.md) に JSON / HTML の説明がある。
- [AI skills](../ai/skills/README.md) には索引を移動する際の注意があるが、説明は複数文書に分散している。
- manifest だけでは照会できず、参照先のセグメントが必要である。HTML は単一ファイルだが、上限付きの部分グラフであり、索引の代用品ではない。
- [セキュリティ](../docs/security.md) C-7 は、識別子やコメント抜粋に秘匿情報が含まれる可能性を警告している。

## 利用者の困りごと

生成後に「AI に渡すもの」「人に見せるもの」「保存・移動するもの」を選びにくい。整合性検証を鮮度確認と取り違えたり、HTML を全体グラフと誤解したりする余地がある。

## 改善内容

- 日本語の利用ガイドに、索引一式、manifest、JSON 応答、HTML、元ソースの役割と依存関係をまとめる。
- 「コード調査を AI に依頼」「人が関係を確認」「別の場所で再利用」の用途別に、入力、コマンド、確認すべき出力を示す。
- `context` の JSON を必要な部分だけ利用し、返されたパスと行範囲を元ソースで確認する例を示す。バイナリや HTML 全体を AI に読ませない。
- 別ディレクトリの索引を `--out` で指定する例、同じソースの別配置での利用、再生成の判断、破損時の安全な復旧を説明する。
- コピー中に世代切替が起こらない条件と、manifest が参照する全セグメントを一緒に保持する手順を示す。ロックや staging を手動削除させない。
- 共有前に確認する情報を生成物別に示す。本文を含まない出力でも、パス・識別子・抽出コメント等の機密性を別途確認する。
- `complete`、`valid`、`truncated`、確度、終了コードの意味を対比し、いずれも「現在のソースを完全に理解した」保証ではないことを示す。

## 対象外

保存形式の再設計、ネットワーク共有サービス、自動アップロード、新しいバックアップ機能。
