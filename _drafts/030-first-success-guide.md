# [P1] 実データで最後まで試せる入門手順を用意する

- 状態: 未着手
- 種別: 利用資料 / 初回利用
- 起票日: 2026-09-27
- 依存: なし。現行 CLI の機能だけで対応する。

## 確認した事実

- [README](../README.md) の「索引と照会」はコマンド一覧だが、入力は `<path>` や `<node-id>` である。
- [クエリと CLI](../docs/query-and-cli.md) 7.1 に最小の利用手順はあるが、入力リポジトリと検索結果から取得する ID が具体的につながっていない。
- [AI skills](../ai/skills/README.md) には導入・コンテキスト指定の説明がある。CLI 自体の入門資料とは目的が異なり、英語で提供されている。
- ネイティブ解析器なしでも T1 は利用できる一方、CLI の既定は T2 であり、初回から診断付き終了になる条件を理解する必要がある。

## 利用者の困りごと

ビルドはできても、「何を検索すれば結果が出るか」「どの ID を次に使うか」「成功時に何が得られるか」を自分で補わなければならない。

## 改善内容

- 既存の [テストコーパス](../tests/corpus/) から小さな入力を選び、導入、T1 索引、検証、検索、属性表示、近傍照会、HTML 出力までをつなぐ。
- 実際の検索結果から次の ID を取得する。説明用の架空 ID を実行例に使わない。
- 各段階に短い出力例と確認点を付け、最後に返されたパス・行範囲から元のソースを確認する。
- macOS のシェルと Windows PowerShell の実行例を用意し、作業ディレクトリと出力先を明示する。
- ネイティブ解析器を使う C / C++ の T2 は次の手順として分離する。SDK と runtime、終了コード 0 / 4 の違いも説明する。
- README から入門手順へ直接誘導し、オプションの詳説は既存のリファレンスへリンクする。

## 対象外

新しいコマンド、配布方式、抽出機能の実装。既存リファレンス全文の複製。

## 受け入れ条件

- [ ] 必要な SDK と復元済み依存を持つ環境で、掲載例を上から実行すると実在する検索結果と HTML を得られる。
- [ ] ネイティブ解析器なしの T1 手順を macOS と Windows で検証し、環境と結果を記録する。
- [ ] ID、パス、行範囲、診断、打ち切り表示の読み方を実際の出力に結び付けて説明する。
- [ ] 検索結果が空、解析器がない、別の出力先を使う場合の参照先がある。
- [ ] README と関連資料から到達でき、リンクが切れていない。

## 完了時の扱い

検証結果と完了日を追記し、[運用ルール](README.md) に従ってこのファイルを `_drafts/_completed/` へ移動する。起票・資料案の作成だけでは移動しない。
