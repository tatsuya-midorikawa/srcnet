# [P1] ignore ファイルをリンク解決前に読まない

- 種別: セキュリティー / ルート境界
- 対象: `src/Srcnet.Discovery/Walk.fs:139-147,228-252`
- 信頼度: 100%

## 問題

`.gitignore` と `.srcnetignore` は、通常エントリに適用しているリンク方針とルート包含確認より先に `File.ReadLines` で開かれる。したがって `--follow-symlinks` を指定していなくても、ignore ファイルが指す解析ルート外のファイルを読み込む。

## 確認結果

解析ルート外に `secret.txt` を無視する規則を置き、解析ルート内の `.gitignore` をそのファイルへのシンボリックリンクにした。

- 外部規則が適用され、ルート内の `secret.txt` は索引されなかった
- マニフェストは `complete: true` だった

## 影響

- 信頼境界外のファイルを意図せず読み取る
- 外部ファイルの内容で索引対象を操作される
- 通常ファイルに対するリンク拒否方針と、マニフェストの完全性表示が一致しない

## 対応案

- ignore ファイルも通常エントリと同じ順序で属性、リンク、実体パスを検証する
- 解析ルート内に実体がある通常ファイルだけを読み込む
- `--follow-symlinks` の有無にかかわらず、ignore 規則の信頼境界を解析ルート内に固定する
- Windows の reparse point も拒否する

## 完了条件

- ルート外へのシンボリックリンク、junction、リンク連鎖を使ったテストがある
- 外部 ignore ファイルの規則が適用されず、外部ファイルも開かれない
- 拒否を完全性に影響する診断として記録する
