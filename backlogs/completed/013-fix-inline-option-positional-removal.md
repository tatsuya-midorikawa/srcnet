# [P3] インラインオプション値と同じ位置引数を削除しない

- 種別: CLI 引数解析
- 対象: `src/Srcnet.Cli/Args.fs:99-159,218-249`
- 信頼度: 100%

## 問題

`split` は `--option=value` の値を位置引数へ追加しない。一方、`OptionReader.Value` は空白区切り形式との重複除去のため、値と同じ文字列を `positional.Remove` で削除する。

トークン位置ではなく文字列一致で削除するため、インライン値と同じ正当な位置引数が消える。

## 確認結果

`repo` ディレクトリが存在する場所で次を実行した。

```text
srcnet index repo --repo=repo
```

- 終了コードは `2`
- `引数 <path> が必要です` と誤報した

## 対応案

- オプション値がインライン形式か、次トークン形式かを保持する
- 次トークン形式の場合だけ、その特定トークンを位置引数から除外する
- 可能なら最初の走査でトークン位置を使って option / value / positional を確定し、値による後処理をなくす

## 完了条件

- `index repo --repo=repo` が `repo` を解析ルートとして受理する
- `--out=out out`、同じ値の位置引数が複数ある場合も正しく解析する
- `--repo repo` の空白区切り形式と、未知オプション・値欠落の既存エラーを維持する
