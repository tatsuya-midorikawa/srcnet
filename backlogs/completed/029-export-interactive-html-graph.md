# [P1] 人間向けの対話的な HTML グラフを出力する

- 種別: 実装 / M4
- 対象: `src/Srcnet.Cli/Args.fs`, `src/Srcnet.Cli/Commands.fs`, `src/Srcnet.Storage/`, `tests/Srcnet.Tests/`, `docs/query-and-cli.md`
- 依存: 028
- 参照: [クエリと CLI](../docs/query-and-cli.md) 4, 5, [ストレージ](../docs/storage.md) 7-9, [ロードマップ](../docs/roadmap.md) M4, M6

## 背景

srcnet の成果物は大規模グラフを効率よく読むためのバイナリであり、VS Code やブラウザーで直接確認できない。一方、人間が抽出結果の妥当性、ハブ、孤立ノード、意外な接続を確認するには、graphify のようにブラウザーで探索できる表示が必要である。

Chromium 系コーパスの全 1,152,071 ノードをブラウザーへ渡すのは現実的でない。全体 JSON を埋め込むのではなく、028 の照会結果から有界な部分グラフまたは集約グラフを作る必要がある。

## やること

- `srcnet export html` を追加し、単一の自己完結 HTML ファイルを生成する
  - 既定出力は `<repo>/.srcnet/graph.html`
  - `--query <text>` または `--node <id>` で起点を指定する
  - `--depth <n>` と `--max-nodes <n>` で範囲を制限する
  - 起点なしでは、現在の `CONTAINS` グラフをディレクトリ単位に集約した概要を出す
- HTML に次の操作を持たせる
  - ズーム、パン、ノード選択、名前・パス検索
  - ノード種別、エッジ種別、向きによる表示切替
  - 選択ノードの属性、定義位置、入出力エッジの表示
  - 打ち切り、集約、診断、元の総ノード数を常に見える形で表示する
- 表示データは決定的な順序で埋め込み、同じ成果物と引数からバイト単位に同じ HTML を生成する
- 外部 CDN、ネットワーク通信、テレメトリを使わない。CSS、JavaScript、部分グラフのデータを 1 ファイルへ含め、オフラインで開けるようにする
- ノード名、パス、属性を HTML / JavaScript 文脈に応じて安全にエスケープする。`</script>`、引用符、制御文字を含むリポジトリでもスクリプト注入を起こさない
- M6 のコミュニティと中心性が存在する成果物では、コミュニティ色分けとハブ表示を追加する。存在しない成果物でもディレクトリ階層とエッジ種別だけで動作させる
- 全体エクスポートは提供しない。上限超過時はディレクトリの集約または明示的な打ち切りを行い、ブラウザーをフリーズさせない

## 設計上の注意

- 最初から新しい UI プロジェクトや JavaScript ビルド環境を追加しない。少量の HTML / CSS / JavaScript を CLI の埋め込みリソースとして生成し、必要性が実測された場合だけ分離する
- レイアウトは入力順や乱数に依存させない。力学レイアウトを使う場合も固定 seed と反復上限を持たせる
- ソース本文は既定で HTML へ埋め込まない。成果物を共有したときに、意図せずコードを複製しないためである
- SVG DOM をノード数だけ生成すると大規模表示で重くなる。上限内でも実測し、必要なら Canvas を使う
- HTML は監査・探索用であり、AI の一次界面にはしない。AI は 028 の JSON CLI を使う

## 完了条件

- Chromium 系成果物から、集約概要と指定ノード周辺の HTML を生成し、Edge / Chrome でネットワークなしに開ける
- CJK、絵文字、HTML 特殊文字を含む名前とパスが欠落・文字化け・スクリプト実行なしに表示される
- `--max-nodes` を超える入力で打ち切りまたは集約が表示され、ブラウザーがフリーズしない
- 同じ成果物と引数から、macOS と Windows でバイト単位に同じ HTML が出る
- 破損成果物や存在しない起点では不完全な HTML を成功扱いで残さず、既存ファイルを保持したまま明示的に失敗する
- 代表的な 500、2,000、5,000 ノードの部分グラフについて、生成時間、HTML サイズ、初回描画時間、ブラウザーのピークメモリを記録する
