# AI skills

This directory contains distributable agent skills. Each package has a
`SKILL.md` with discovery metadata and instructions.

| Skill | Purpose |
| --- | --- |
| [srcnet](srcnet/SKILL.md) | Reuse a srcnet index through bounded JSON queries, then confirm relevant source |

## Make the skill available to an agent

`ai/skills/` is the authoring location, not a default Copilot skill-discovery
directory. Copy the complete `srcnet/` directory to the desired location:

| Scope | Copilot location |
| --- | --- |
| One target repository | `<target-repository>/.github/skills/srcnet/SKILL.md` |
| Personal, across repositories | `~/.copilot/skills/srcnet/SKILL.md` |

Other clients have their own skill-discovery locations. Review an existing
destination before replacing it. This repository does not automatically install
the skill, change global configuration, or create an index.

## Provide the working context

Tell the agent the trusted srcnet executable, the original source root and the
index directory containing `manifest.json`. An existing index outside the source
tree is supported through `--out`; the default location is `<source-root>/.srcnet`.
The agent needs access to those paths. Keep machine-specific paths in local
configuration or prompts, not in the distributed skill.

`manifest.json` is generated by `srcnet index`; it is not a configuration file
to fill in. The [sample manifest](srcnet/manifest.example.json) beside `SKILL.md`
shows a real small index's metadata. The skill explains each field and how to
generate an index. The sample alone is not usable without its matching binary
segments, and should not replace an existing manifest.

For example, ask the agent to use the existing srcnet index to find relevant
files for a feature, inspect their neighborhoods, and read only the source needed
to explain the result. The skill defaults to read-only investigation and does
not rebuild the index automatically.

For continued use, choose a stable index location rather than relying on a
session directory that may later be removed. The skill does not eliminate the
current extraction limitations; its workflow explicitly checks diagnostics,
truncation, freshness and original-source evidence.
