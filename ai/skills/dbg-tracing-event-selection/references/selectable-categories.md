# Selectable Categories Snapshot

Snapshot date: 2026-05-20

This file lists the non-group categories exposed to edge://tracing / chrome://tracing by the current reference snapshot. The UI splits categories by name:

- `Record Categories`: names that do not start with `disabled-by-default-`
- `Disabled by Default Categories`: names that start with `disabled-by-default-`

The snapshot was extracted from the base, V8, and WebRTC TrackEvent registries used by the tracing controller. Category groups are intentionally excluded because the tracing controller excludes group categories before sending the list to the UI.

Counts:

- Record Categories: 241
- Disabled by Default Categories: 116
- Total: 357

Notes:

- Edge-specific categories are included because this skill targets Microsoft Edge. Some are only available in Edge branded builds.
- Platform-specific categories can appear in the registry even when a scenario is not relevant to the current OS.
- The UI also merges persisted category settings from the user profile; this file covers categories supplied by the tracing registries.
